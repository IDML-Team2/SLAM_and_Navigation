# IMDL – SLAM and Navigation with Create3, Jetson and RPLidar

Build a map of a room with SLAM and let the robot drive to coordinates on it.

## Structure

| Folder / file | Content |
| --- | --- |
| `imdl_nav_ws/` | the ROS 2 workspace: package `imdl_nav` with launch files, nodes, configuration |
| `imdl_nav_ws/notebooks/` | Jupyter notebooks to explore laser scans, maps and poses |
| `docker/` | ROS 2 Humble container for the PC, with everything installed |
| `TUTORIAL_SLAM_NAVIGATION.md` | full step-by-step explanations |

**To run SLAM and navigation with the robot, follow
[imdl_nav_ws/README.md](imdl_nav_ws/README.md).**
